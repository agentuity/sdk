title: Email

Use email when your app needs managed sending, inbound addresses, and delivery history. Start with `EmailClient`; Hono apps can use `c.var.email` after installing the Agentuity middleware.

```bash
bun add @agentuity/email@alpha
```

```typescript
import { EmailClient } from '@agentuity/email';

const email = new EmailClient();

export async function sendWelcomeEmail(to: string): Promise<string> {
  const result = await email.send({
    from: 'notifications@agentuity.email',
    to: [to],
    subject: 'Welcome',
    text: 'Your workspace is ready.',
    html: '<p>Your workspace is ready.</p>',
  });

  return result.id;
}
```

`EmailClient` reads `AGENTUITY_SDK_KEY` by default. In Agentuity projects, keep the key in `.env` for local `agentuity dev` and configure the same environment variable for deployed apps.

## When to Use Email

| Need | Use |
|------|-----|
| send transactional or notification email | [Email](/services/email) |
| receive email at managed addresses | [Email](/services/email) |
| receive HTTP callbacks from external services | [Webhooks](/services/webhooks) |
| hand email work to a background process | [Queues](/services/queues) |

## Client Setup

Construct the client once at module scope and reuse it from handlers, routes, or scripts.

```typescript
import { EmailClient } from '@agentuity/email';

const email = new EmailClient({
  orgId: process.env.AGENTUITY_ORG_ID,
});
```

| Option | Description |
|--------|-------------|
| `apiKey` | Optional API key. Defaults to `AGENTUITY_SDK_KEY`, then `AGENTUITY_CLI_KEY`. |
| `orgId` | Optional organization ID for org-scoped requests. |
| `url` | Optional Email API URL. Defaults to `AGENTUITY_EMAIL_URL`, then the regional Agentuity email service URL. |
| `logger` | Optional logger instance. |

## Create Addresses

Email addresses use the `@agentuity.email` domain. You provide the local part before the `@`.

```typescript
const address = await email.createAddress('support');

const addresses = await email.listAddresses();
const current = await email.getAddress(address.id);
```

Address IDs are prefixed with `eaddr_`. Delete an address only when you no longer need inbound or outbound records associated with it.

```typescript
await email.deleteAddress(address.id);
```

## Send Email

`send()` queues the outbound email and returns an outbound record.

```typescript
const outbound = await email.send({
  from: 'support@agentuity.email',
  to: ['customer@example.com'],
  subject: 'We received your request',
  text: 'Thanks. We will follow up shortly.',
  headers: {
    'X-Ticket-ID': 'task_123',
  },
});
```

| Field | Required | Description |
|-------|----------|-------------|
| `from` | Yes | Sender address owned by the organization. |
| `to` | Yes | Recipient email addresses. |
| `subject` | Yes | Email subject. |
| `text` | No | Plain text body. |
| `html` | No | HTML body. |
| `attachments` | No | Base64-encoded attachments. |
| `headers` | No | Custom email headers, such as `In-Reply-To` or `References`. |

Outbound records can be `pending`, `success`, or `failed`.

```typescript
const delivered = await email.getOutbound(outbound.id);
const outboundForAddress = await email.listOutbound(address.id);
```

## Attachments

Attachments are included as base64 content in the `attachments` array.

```typescript
const csv = Buffer.from('date,total\n2026-04-28,42').toString('base64');

await email.send({
  from: 'reports@agentuity.email',
  to: ['manager@example.com'],
  subject: 'Daily report',
  text: 'The report is attached.',
  attachments: [
    {
      filename: 'daily-report.csv',
      content: csv,
      contentType: 'text/csv',
    },
  ],
});
```

Keep the full RFC 822 message, including attachments, under the service size limit for your org.

## Inbound Email

List inbound messages across the organization, or pass an address ID to filter.

```typescript
const allInbound = await email.listInbound();
const supportInbound = await email.listInbound(address.id);
const firstInbound = supportInbound.at(0);

const message = firstInbound
  ? await email.getInbound(firstInbound.id)
  : null;
```

Inbound email records include sender, recipient, subject, optional text, optional HTML, headers, and stored attachment metadata.

```typescript
await email.deleteInbound('einb_123');
```

## Destinations

Destinations forward inbound emails to an HTTP endpoint as they arrive.

```typescript
const destination = await email.createDestination(address.id, 'url', {
  url: 'https://api.example.com/email/inbound',
  method: 'POST',
  headers: {
    'X-Email-Source': 'agentuity',
  },
});

const destinations = await email.listDestinations(address.id);

await email.deleteDestination(address.id, destination.id);
```

For `url` destinations, pass a public `http` or `https` URL. Destination IDs are prefixed with `edst_`.

## Connection Config

Use `getConnectionConfig()` when a mail client needs IMAP or POP3 access to an Agentuity address.

```typescript
const config = await email.getConnectionConfig(address.id);

if (config) {
  const imapHost = config.imap.host;
  const pop3Host = config.pop3.host;
}
```

The returned config includes `host`, `port`, `tls`, `username`, and `password` for both protocols.

## Activity

Use `getActivity()` for daily inbound and outbound counts.

```typescript
const activity = await email.getActivity({ days: 30 });
```

The `days` option defaults to 7. Values outside the supported range are clamped by the service.

## Hono

In Hono apps, `@agentuity/hono` initializes `EmailClient` once and exposes it on `c.var.email`.

```bash
bun add @agentuity/hono@alpha hono
```

```typescript
import { Hono } from 'hono';
import { agentuity } from '@agentuity/hono';
import type { Services } from '@agentuity/hono';

type Variables = Pick<Services, 'email'>;

const app = new Hono<{ Variables: Variables }>();

app.use('*', agentuity());

app.post('/notify', async (c) => {
  const to = c.req.query('to');

  if (!to) {
    return c.json({ error: 'to is required' }, 400);
  }

  const outbound = await c.var.email.send({
    from: 'notifications@agentuity.email',
    to: [to],
    subject: 'Notification',
    text: 'You have a new notification.',
  });

  return c.json({ id: outbound.id, status: outbound.status }, 202);
});

export default app;
```
