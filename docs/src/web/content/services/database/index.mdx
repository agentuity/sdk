Use database storage when your app needs SQL, joins, constraints, or transactions. Agentuity database resources are Postgres databases, and v3 apps access them with direct clients.

## Create or Link a Database

```bash
agentuity cloud db create --name app_data
agentuity project add database app_data
```

Creating a database from a project, or linking an existing database to a project, writes `DATABASE_URL` to your local `.env`. If you do not need a specific name, omit `--name` and let the CLI generate one.

## Choose a Database Client

| Need | Use |
|------|-----|
| tagged SQL from Bun server code | [`@agentuity/postgres`](/services/database/postgres) |
| type-safe schema-first queries from Bun app code | [`@agentuity/drizzle`](/services/database/drizzle) |
| query an Agentuity database by resource name and org ID | `@agentuity/db` |

Use `@agentuity/postgres` or `@agentuity/drizzle` inside Bun app code that has `DATABASE_URL`. Use `DBClient` for scripts and admin tools that should call the Agentuity database service API instead of opening a direct Postgres connection.

## Use Postgres from App Code

`@agentuity/postgres` wraps Bun's SQL driver with reconnection behavior. It reads `DATABASE_URL` by default.

```bash
bun add @agentuity/postgres@alpha
```

```typescript
import { postgres } from '@agentuity/postgres';

const sql = postgres();

const activeUsers = await sql`
  SELECT id, email
  FROM users
  WHERE active = ${true}
  ORDER BY created_at DESC
  LIMIT ${10}
`;
```

<Callout type="warning" title="Use template values for dynamic SQL">
Pass dynamic values through `${value}` in the tagged template. Do not concatenate user input into SQL strings.
</Callout>

## Use Drizzle

Use `@agentuity/drizzle` when you want Drizzle ORM queries on the same Postgres resource. The default driver uses `pg` through Agentuity's resilient pool. Set `driver: 'bun-sql'` only when you specifically want Bun SQL.

```bash
bun add @agentuity/drizzle@alpha drizzle-orm
```

```typescript
import { createPostgresDrizzle, boolean, eq, pgTable, serial, text } from '@agentuity/drizzle';

const users = pgTable('users', {
  id: serial('id').primaryKey(),
  email: text('email').notNull().unique(),
  active: boolean('active').notNull().default(true),
});

const { db, close } = createPostgresDrizzle({
  schema: { users },
});

try {
  const activeUsers = await db.select().from(users).where(eq(users.active, true));
} finally {
  await close();
}
```

For schema files that are imported by `drizzle-kit`, use the schema-only entry point:

```typescript title="src/db/schema.ts"
import { boolean, pgTable, serial, text } from '@agentuity/drizzle/schema';

export const users = pgTable('users', {
  id: serial('id').primaryKey(),
  email: text('email').notNull().unique(),
  active: boolean('active').notNull().default(true),
});
```

## Query Through the Database Service API

`DBClient` calls the Agentuity database service API by database name and org ID. Use it for scripts that inspect tables, run administrative queries, or read query logs without opening a direct Postgres connection from the script.

```bash
bun add @agentuity/db@alpha
```

```typescript
import { DBClient } from '@agentuity/db';

const database = process.env.AGENTUITY_DB_DATABASE;
const orgId = process.env.AGENTUITY_ORG_ID;

if (!database || !orgId) {
  throw new Error('AGENTUITY_DB_DATABASE and AGENTUITY_ORG_ID are required');
}

const db = new DBClient({ database, orgId });

const result = await db.query('SELECT 1 AS ok');
const tables = await db.tables();
const logs = await db.logs({ limit: 50 });
```

`DBClient` does not read `DATABASE_URL`. Pass the Agentuity database resource name and organization ID explicitly.

## Framework Routes

Initialize the database client at module scope so framework routes can reuse it between requests.

```typescript title="app/api/users/route.ts"
import { postgres } from '@agentuity/postgres';

const sql = postgres();

export async function GET(): Promise<Response> {
  const users = await sql`
    SELECT id, email
    FROM users
    ORDER BY created_at DESC
    LIMIT ${20}
  `;

  return Response.json({ users });
}
```

Database clients are direct clients. `@agentuity/hono` injects KV, vector, stream, queue, email, schedule, task, and sandbox clients, but it does not inject a database client.
