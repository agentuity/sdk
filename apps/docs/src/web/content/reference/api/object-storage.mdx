## Authentication

All requests require a Bearer token. Pass your SDK key in the `Authorization` header.

| Header | Value |
|--------|-------|
| `Authorization` | `Bearer YOUR_SDK_KEY` |

You can find your SDK key in the [Agentuity Console](https://app.agentuity.com) under your project settings.

## Delete Objects

Delete objects by key or by prefix. `key` and `prefix` are mutually exclusive query parameters.

<ApiEndpoint method="DELETE" path="/storage/objects/{bucket}" />

### Parameters

<ParamTable params={[
  {
    "name": "bucket",
    "type": "string",
    "in": "path",
    "required": true,
    "description": "Bucket name"
  },
  {
    "name": "key",
    "type": "string",
    "in": "query",
    "required": false,
    "description": "Delete a single object key"
  },
  {
    "name": "prefix",
    "type": "string",
    "in": "query",
    "required": false,
    "description": "Delete all objects matching prefix"
  }
]} />

### Response

JSON response with deleted object count.

| Status | Description |
|--------|-------------|
| 200 | Delete operation completed |
| 401 | Unauthorized |

### Response Fields

<ResponseFields fields={[
  {
    "name": "deleted_count",
    "type": "number",
    "description": "Number of objects deleted"
  }
]} />

### Example

<ApiExample method="DELETE" path="/storage/objects/my-bucket?key=images/photo.jpg" />
