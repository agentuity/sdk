This page walks through the framework-first happy path with Next.js. The same flow works for any [supported framework](/get-started/installation#framework-slugs).

## 1. Create the Project

```bash
bun create agentuity@alpha --name my-app --framework nextjs
cd my-app
```

The scaffold runs `create-next-app`, then layers on:

- `@agentuity/cli@alpha` as a devDependency
- `openai`, `@agentuity/keyvalue@alpha`, and `swr` as dependencies
- A working translation page at `src/app/page.tsx`
- An API route at `src/app/api/translate/route.ts` that uses the OpenAI SDK and stores history in key-value storage
- `deploy: agentuity deploy` in `package.json`
- `agentuity.json` with the registered project's metadata
- `.env` with the project's `AGENTUITY_SDK_KEY`

## 2. Run It Locally

```bash
bunx agentuity dev
```

`bunx` runs the alpha CLI from `devDependencies`. The CLI runs `next dev` as a child process and patches `AGENTUITY_SDK_KEY` plus AI Gateway base URLs into its env, so the OpenAI SDK call routes through Agentuity. Open the URL Next.js prints (typically `http://localhost:3000`) and try a translation.

You can also call the API route directly:

```bash
curl -X POST http://localhost:3000/api/translate \
  -H "Content-Type: application/json" \
  -d '{"text":"Hello from Agentuity","toLanguage":"French"}'
```

The response includes the translation, the session id, the running translation count, and the most recent history (stored in KV under `translation-history`).

## 3. Make an Edit

Open `src/app/page.tsx` and add a language to the picker:

```tsx title="src/app/page.tsx"
const LANGUAGES = ['Spanish', 'French', 'German', 'Chinese', 'Japanese'] as const;
```

Save the file. Next.js hot-reloads, the new option appears in the dropdown, and the route accepts it without any other change.

## 4. Add Another Service

Service clients work in any framework route or script. Add a second namespace next to the translation history without touching the runtime:

```typescript title="src/app/api/translate/route.ts"
import { KeyValueClient } from '@agentuity/keyvalue';

const kv = new KeyValueClient();

await kv.set('analytics', 'last-translation-at', { at: new Date().toISOString() });
```

The client reads `AGENTUITY_SDK_KEY` from process env. `agentuity dev` supplies that key for local runs, and registered deployed apps receive it as a project secret.

See [Services](/services) for queues, vector storage, email, schedules, sandbox execution, and the rest.

## 5. Deploy

```bash
bun run deploy
```

The `deploy` script runs `agentuity deploy`, which:

- Detects the framework from `package.json` and config files
- Runs the framework's build, then packages the output into `.agentuity/`
- Encrypts the bundle, uploads it, and starts the deployment

The CLI prints both the deployment-specific URL and the latest deployment URL. Visit either in a browser, or check [app.agentuity.com](https://app.agentuity.com) for logs and resource settings.
