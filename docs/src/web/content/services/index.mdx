Use Agentuity services when your framework app needs managed state, search, messaging, observability, or code execution. In v3, start with the service's direct client in your framework route, server function, script, or worker.

```typescript
import { KeyValueClient } from '@agentuity/keyvalue';

const kv = new KeyValueClient();

await kv.set('cache', 'homepage', { generatedAt: new Date().toISOString() });
const cached = await kv.get<{ readonly generatedAt: string }>('cache', 'homepage');
```

For method signatures and return types, see the [SDK Reference](/reference/sdk-reference). For environment variables used by service clients, see [App Configuration](/get-started/app-configuration#agentuity-keys).

Hono apps can also install `@agentuity/hono` when they want middleware to create the common clients once and expose them on `c.var.*`.
