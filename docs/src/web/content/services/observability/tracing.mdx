Use tracing when logs tell you something happened but not where the time went. `@agentuity/telemetry` gives framework apps an OpenTelemetry tracer, and `@agentuity/hono` exposes the same tracer as `c.var.tracer` in Hono routes.

```bash
bun add @agentuity/telemetry@alpha @opentelemetry/api
```

## Basic Span Pattern

```typescript
import { SpanStatusCode } from '@opentelemetry/api';
import { logger, tracer } from '@agentuity/telemetry';

interface SearchInput {
  readonly query: string;
  readonly limit: number;
}

export async function searchProducts(input: SearchInput): Promise<readonly string[]> {
  return tracer.startActiveSpan('search-products', async (span) => {
    try {
      span.setAttribute('queryLength', input.query.length);
      span.setAttribute('limit', input.limit);

      const catalog = ['cyan jacket', 'black backpack', 'white notebook'];
      const results = catalog
        .filter((item) => item.includes(input.query.toLowerCase()))
        .slice(0, input.limit);

      span.setAttribute('resultCount', results.length);
      span.setStatus({ code: SpanStatusCode.OK });

      return results;
    } catch (error) {
      const message = error instanceof Error ? error.message : String(error);
      span.recordException(error instanceof Error ? error : new Error(message));
      span.setStatus({ code: SpanStatusCode.ERROR, message });
      logger.child({ error: message }).error('Product search failed');
      throw error;
    } finally {
      span.end();
    }
  });
}
```

`startActiveSpan()` makes the span active while the callback runs, but it does not close the span. Call `span.end()` in a `finally` block, and set status when the outcome is meaningful.

## Adding Attributes

Use attributes for searchable span context: IDs, counts, categories, and boolean flags. Avoid raw prompts, tokens, secrets, or personal data.

```typescript
import { SpanStatusCode } from '@opentelemetry/api';
import { tracer } from '@agentuity/telemetry';

interface UserLookup {
  readonly userId: string;
  readonly source: 'api' | 'job';
}

export async function loadUser(input: UserLookup): Promise<{ readonly found: boolean }> {
  return tracer.startActiveSpan('user-lookup', async (span) => {
    try {
      span.setAttribute('userId', input.userId);
      span.setAttribute('source', input.source);

      const found = input.userId.startsWith('user_');

      span.setAttribute('userFound', found);
      span.setStatus({ code: SpanStatusCode.OK });
      return { found };
    } finally {
      span.end();
    }
  });
}
```

## Recording Events

Use `addEvent()` to mark important moments inside a longer span.

```typescript
import { SpanStatusCode } from '@opentelemetry/api';
import { tracer } from '@agentuity/telemetry';

export async function processBatch(records: readonly string[]): Promise<{ readonly count: number }> {
  return tracer.startActiveSpan('batch-import', async (span) => {
    try {
      span.addEvent('validation-started', { recordCount: records.length });

      const valid = records.filter((record) => record.trim().length > 0);
      span.addEvent('validation-complete', { validCount: valid.length });

      span.setAttribute('recordCount', valid.length);
      span.setStatus({ code: SpanStatusCode.OK });
      return { count: valid.length };
    } finally {
      span.end();
    }
  });
}
```

Events create a timeline inside the span. Use them for milestones, not for every loop iteration.

## Nested Spans

Create child spans for multi-step operations. Inner spans inherit the active parent span.

```typescript
import { SpanStatusCode } from '@opentelemetry/api';
import { tracer } from '@agentuity/telemetry';

export async function answerQuestion(question: string): Promise<{ readonly answer: string }> {
  return tracer.startActiveSpan('answer-question', async (parentSpan) => {
    try {
      parentSpan.setAttribute('questionLength', question.length);

      const context = await tracer.startActiveSpan('load-context', async (span) => {
        try {
          const snippets = ['pricing docs', 'account docs'];
          span.setAttribute('snippetCount', snippets.length);
          span.setStatus({ code: SpanStatusCode.OK });
          return snippets;
        } finally {
          span.end();
        }
      });

      const answer = await tracer.startActiveSpan('compose-answer', async (span) => {
        try {
          span.setAttribute('contextChunks', context.length);
          span.setStatus({ code: SpanStatusCode.OK });
          return `Answer based on ${context.length} snippets`;
        } finally {
          span.end();
        }
      });

      parentSpan.setStatus({ code: SpanStatusCode.OK });
      return { answer };
    } catch (error) {
      const message = error instanceof Error ? error.message : String(error);
      parentSpan.recordException(error instanceof Error ? error : new Error(message));
      parentSpan.setStatus({ code: SpanStatusCode.ERROR, message });
      throw error;
    } finally {
      parentSpan.end();
    }
  });
}
```

Nested spans show parent-child timing in session timeline views.

## Fetch Propagation

After telemetry initializes, `fetch()` calls made inside an active span get a child HTTP span and trace-context headers.

```typescript
import { SpanStatusCode } from '@opentelemetry/api';
import { tracer } from '@agentuity/telemetry';

export async function loadCatalog(): Promise<Response> {
  return tracer.startActiveSpan('load-catalog', async (span) => {
    try {
      const response = await fetch('https://api.example.com/catalog');
      span.setAttribute('status', response.status);
      span.setStatus({ code: response.ok ? SpanStatusCode.OK : SpanStatusCode.ERROR });
      return response;
    } catch (error) {
      const message = error instanceof Error ? error.message : String(error);
      span.recordException(error instanceof Error ? error : new Error(message));
      span.setStatus({ code: SpanStatusCode.ERROR, message });
      throw error;
    } finally {
      span.end();
    }
  });
}
```

## AI SDK Telemetry

AI SDK calls emit OpenTelemetry spans when telemetry is enabled for the call. Pass the Agentuity tracer when you want those spans to share the same trace pipeline as your framework code.

```typescript
import { generateText } from 'ai';
import { tracer } from '@agentuity/telemetry';

await generateText({
  model,
  prompt,
  experimental_telemetry: {
    isEnabled: true,
    functionId: 'translate-text',
    metadata: {
      route: 'POST /api/translate',
    },
    tracer,
  },
});
```

In local testing with AI SDK 6, `generateText()` produced `ai.generateText` and `ai.generateText.doGenerate` spans. `streamText()` produced `ai.streamText` and `ai.streamText.doStream` spans plus `ai.stream.firstChunk` and `ai.stream.finish` events. Token counts appear on span attributes such as `ai.usage.inputTokens`, `ai.usage.outputTokens`, and `ai.usage.totalTokens`.

Telemetry metadata is copied to `ai.telemetry.metadata.*` span attributes. Session or request IDs are not added by the AI SDK on their own; pass the IDs you want to search for in `metadata`.

## Hono Routes

Hono routes can read the tracer from `c.var.tracer` after installing the Agentuity middleware.

```bash
bun add @agentuity/hono@alpha @opentelemetry/api hono
```

```typescript
import { Hono } from 'hono';
import { agentuity } from '@agentuity/hono';
import { SpanStatusCode } from '@opentelemetry/api';
import type { Logger } from '@agentuity/hono';
import type { Tracer } from '@opentelemetry/api';

interface Env {
  readonly Variables: {
    readonly logger: Logger;
    readonly tracer: Tracer;
  };
}

const app = new Hono<Env>();

app.use('*', agentuity({ telemetry: { logLevel: 'info' } }));

app.post('/customers/:id/notify', async (c) => {
  return c.var.tracer.startActiveSpan('send-notification', async (span) => {
    try {
      const customerId = c.req.param('id');
      span.setAttribute('customerId', customerId);

      c.var.logger.child({ customerId }).info('Notification accepted');
      span.setAttribute('delivered', true);
      span.setStatus({ code: SpanStatusCode.OK });
      return c.json({ delivered: true });
    } catch (error) {
      const message = error instanceof Error ? error.message : String(error);
      span.recordException(error instanceof Error ? error : new Error(message));
      span.setStatus({ code: SpanStatusCode.ERROR, message });
      throw error;
    } finally {
      span.end();
    }
  });
});

export default app;
```

## Viewing Traces

View traces for a session using the CLI:

```bash
agentuity cloud session get sess_abc123xyz
```

The command includes the session timeline when it is available. Traces are also visible in the [Agentuity Console](https://app.agentuity.com) session timeline.

## When to Use Tracing

| Scenario | Approach |
|----------|----------|
| Simple operations | Logging is sufficient |
| Multi-step workflows | Create spans for each step |
| Performance debugging | Add spans to identify bottlenecks |
| External API calls | Wrap in spans to track latency |
| Cross-service calls | Let trace context propagate through active spans and fetch |

## Best Practices

- Name spans after work, not implementation steps: `generate-summary`, not `step-2`.
- End every span in `finally`.
- Set `SpanStatusCode.OK` or `SpanStatusCode.ERROR` when the outcome matters.
- Add IDs, counts, categories, and booleans as attributes.
- Keep sensitive payloads out of span attributes and events.
- Use events for milestones inside long operations.
