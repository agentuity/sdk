## Quick Reference

| Need | Use |
|------|-----|
| application logs | `logger` from `@agentuity/telemetry` |
| route logs in Hono | `c.var.logger` from `@agentuity/hono` |
| custom spans | `tracer` from `@agentuity/telemetry` or `c.var.tracer` in Hono |
| request/session history | `agentuity cloud session` and the Agentuity Console |
| deployment output | `agentuity cloud deployment logs` |
| browser page views and events | v2 web analytics or a framework-owned analytics tool while v3 analytics UI is finalized |

## Access Patterns

| App Shape | Logging | Tracing | Analytics |
|-----------|---------|---------|-----------|
| Any server framework or script | `logger` from `@agentuity/telemetry` | `tracer` from `@agentuity/telemetry` | framework analytics |
| Hono with `@agentuity/hono` | `c.var.logger` | `c.var.tracer` | framework analytics |
| CLI and Console inspection | session and deployment log commands | session timeline views | v2 web analytics views |

```bash
bun add @agentuity/telemetry@alpha
```

```typescript
import { logger, tracer } from '@agentuity/telemetry';

logger.child({ route: 'POST /api/chat' }).info('Request received');

await tracer.startActiveSpan('load-context', async (span) => {
  try {
    span.setAttribute('source', 'kv');
    return { ready: true };
  } finally {
    span.end();
  }
});
```

`@agentuity/telemetry` reads Agentuity environment variables in dev and deployed environments. Use explicit `register()` options when the code runs outside an Agentuity project or you want to set service metadata yourself.

## Hono Middleware

Hono apps can install one middleware to initialize telemetry and inject Agentuity services into `c.var`.

```bash
bun add @agentuity/hono@alpha @opentelemetry/api hono
```

```typescript
import { Hono } from 'hono';
import { agentuity } from '@agentuity/hono';
import type { Logger } from '@agentuity/hono';
import type { Tracer } from '@opentelemetry/api';

interface Env {
  readonly Variables: {
    readonly logger: Logger;
    readonly tracer: Tracer;
  };
}

const app = new Hono<Env>();

app.use('*', agentuity({ telemetry: { logLevel: 'info' } }));

app.get('/health', (c) => {
  c.var.logger.info('Health check');
  return c.json({ ok: true });
});

export default app;
```

## Sessions

Sessions are platform observability records. The v3 framework docs do not teach runtime `ctx.session` or `ctx.thread` as the default app API, but the CLI and Console can inspect session records created by deployed or dev-mode framework requests when that data is available.

```bash
agentuity cloud session list
agentuity cloud session get sess_abc123xyz
agentuity cloud session logs sess_abc123xyz
```
