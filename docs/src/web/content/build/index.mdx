## Pick a Starting Point

| If you need to... | Start with | Mental model |
| --- | --- | --- |
| Run a model-backed workflow from a route, job, or script | [Build Agents](/build/agents) | An agent is app code that calls a model and returns a typed result |
| Send tokens to the browser as they arrive | [Chat and Streaming](/build/chat-and-streaming) | The framework owns the response stream; storage is explicit |
| Let a model call bounded app functions | [Tool Calling](/build/tool-calling) | Tools are validated functions you own |
| Remember user or conversation state | [State and Memory](/build/state-and-memory) | Pick KV, database rows, cookies, or vector storage by access pattern |
| Keep slow work out of request handlers | [Background Work](/build/background-work) | Queue, task, schedule, or stream the work outside the request path |

The examples use direct service clients because that path works across all supported frameworks and scripts. Hono apps can also install `@agentuity/hono` and read the same clients from `c.var.*`.
