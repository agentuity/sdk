## When to Use What

| I want to... | Use |
|---|---|
| Use Agentuity services from Node.js, Bun, scripts, workers, or server routes | [Standalone Packages](/reference/standalone-packages) |
| Add Agentuity to Next.js, Hono, TanStack Start, or another framework app | [Framework Apps](/frameworks) |
| Create, deploy, or manage projects from the terminal | [CLI Reference](/reference/cli) |
| Call Agentuity services from any language via HTTP | [REST API Reference](/reference/api) |
| Compare storage, messaging, observability, execution, and Coder services | [Service Guides](/services) |
| Maintain an existing v2 runtime app that uses `createApp()`, `createAgent()`, `ctx.*`, or runtime routes | [SDK Reference](/reference/sdk-reference) |
