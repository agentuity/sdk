Agentuity v3 does not require a special Tailwind setup. Use the Tailwind path your framework expects, then keep Agentuity service clients in server routes.

## Vite-Based Apps

For Vite-based apps, use Tailwind's Vite plugin:

```bash
bun add -D tailwindcss @tailwindcss/vite
```

```typescript title="vite.config.ts"
import tailwindcss from '@tailwindcss/vite';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [tailwindcss()],
});
```

Import Tailwind from the CSS file your framework already loads:

```css title="src/styles.css"
@import 'tailwindcss';
```

Then use Tailwind classes in your components:

```tsx
export function EmptyState() {
  return (
    <section className="mx-auto max-w-xl rounded-lg border border-zinc-800 p-6">
      <h1 className="text-xl font-semibold text-zinc-50">No sessions yet</h1>
      <p className="mt-2 text-sm text-zinc-400">
        Start a Coder session or run an API route to create your first record.
      </p>
    </section>
  );
}
```

## Framework Apps

If your app uses Next.js, TanStack Start, SvelteKit, Astro, Nuxt, or React Router, follow that framework's Tailwind guide. Agentuity deploys the built framework output and does not need its own Tailwind config.
