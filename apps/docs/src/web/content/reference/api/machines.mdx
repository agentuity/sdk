## Authentication

All requests require a Bearer token. Pass your SDK key in the `Authorization` header.

| Header | Value |
|--------|-------|
| `Authorization` | `Bearer YOUR_SDK_KEY` |

You can find your SDK key in the [Agentuity Console](https://app.agentuity.com) under your project settings.

## Machine Management

### List Machines

<ApiEndpoint method="GET" path="/machine" />

List all machines visible to the authenticated user.



#### Response

Returns all machines visible to the authenticated user.

| Status | Description |
|--------|-------------|
| 200 | Machines returned |
| 401 | Unauthorized — invalid or missing Bearer token |

## Auth Enrollment

### Enroll Organization

<ApiEndpoint method="POST" path="/cli/auth/org/enroll" />

Enroll an organization for machine authentication.


#### Request Body

Enrollment payload with organization ID and public key.

<ResponseFields fields={[
  {
    "name": "orgId",
    "type": "string",
    "description": "Organization ID",
    "required": true
  },
  {
    "name": "publicKey",
    "type": "string",
    "description": "Public key for machine authentication",
    "required": true
  }
]} />

#### Response

Returns the enrolled organization ID.

| Status | Description |
|--------|-------------|
| 200 | Organization enrolled |
| 401 | Unauthorized — invalid or missing Bearer token |

#### Response Fields

<ResponseFields fields={[
  {
    "name": "orgId",
    "type": "string",
    "description": "The enrolled organization ID"
  }
]} />

#### Example

<ApiExample method="POST" path="/cli/auth/org/enroll" body={{
  "orgId": "org_abc123",
  "publicKey": "ssh-ed25519 AAAA..."
}} />

### Get Enrollment Status

<ApiEndpoint method="GET" path="/cli/auth/org/status/{orgId}" />

Get the enrollment status for an organization.

#### Parameters

<ParamTable params={[
  {
    "name": "orgId",
    "type": "string",
    "in": "path",
    "required": true,
    "description": "Organization ID"
  }
]} />

#### Response

Returns the enrollment status. A null publicKey means not enrolled.

| Status | Description |
|--------|-------------|
| 200 | Enrollment status returned |
| 401 | Unauthorized — invalid or missing Bearer token |
| 404 | Organization not found |

#### Response Fields

<ResponseFields fields={[
  {
    "name": "publicKey",
    "type": "string",
    "description": "Public key or null if not enrolled"
  }
]} />

#### Example

<ApiExample method="GET" path="/cli/auth/org/status/org_abc123" />
