title: Quickstart
description: Create a framework app, add an AI route, and deploy it to Agentuity
---

Use Next.js here as the concrete path. You will create a framework app, add a server route, run it through `agentuity dev`, and deploy it.

## 1. Create the Project

```bash
bun create agentuity@alpha --name my-app --framework nextjs
cd my-app
```

The starter creates a Next.js app, adds the Agentuity CLI, and includes a small AI example route.

<Callout type="info" title="Frameworks are the starting point">
You can use `nuxt`, `remix`, `sveltekit`, `astro`, `hono`, or `vite-react` instead. See [Installation](/get-started/installation): supported framework slugs and create options.
</Callout>

## 2. Run the App

```bash
agentuity dev
```

Open the URL printed by Next.js. For a default Next.js app, that is usually `http://localhost:3000`.

Test the generated translation route:

```bash
curl -X POST http://localhost:3000/api/translate \
  -H "Content-Type: application/json" \
  -d '{"text":"Hello from Agentuity","toLanguage":"French"}'
```

## 3. Add a Chat Route

Add validation for the request body:

```bash
bun add zod
mkdir -p src/app/api/chat
```

Create `src/app/api/chat/route.ts`:

```typescript title="src/app/api/chat/route.ts"
import OpenAI from 'openai';
import { NextResponse } from 'next/server';
import { z } from 'zod';

const ChatRequest = z.object({
  message: z.string().min(1),
});

const openai = new OpenAI();

export async function POST(request: Request): Promise<NextResponse> {
  const body: unknown = await request.json();
  const parsed = ChatRequest.safeParse(body);

  if (!parsed.success) {
    return NextResponse.json({ error: 'Invalid chat request' }, { status: 400 });
  }

  const completion = await openai.chat.completions.create({
    model: 'gpt-5.4-mini',
    messages: [{ role: 'user', content: parsed.data.message }],
  });

  return NextResponse.json({
    response: completion.choices[0]?.message?.content ?? '',
  });
}
```

With `AGENTUITY_SDK_KEY` set, `agentuity dev` can route OpenAI SDK calls through Agentuity during local development. If your app already uses `OPENAI_API_KEY`, it can keep using it.

## 4. Call the Route

Keep `agentuity dev` running, then call the new route:

```bash
curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"Give me one sentence about Agentuity."}'
```

Response:

```json
{
  "response": "Agentuity helps you run AI apps and services from your TypeScript framework."
}
```

## 5. Add Services When You Need Them

Framework routes can use Agentuity services through standalone clients. For example, add key-value storage to any server route or script:

```bash
bun add @agentuity/keyvalue@alpha
```

```typescript
import { KeyValueClient } from '@agentuity/keyvalue';

const kv = new KeyValueClient();

await kv.set('chat', 'latest-message', {
  message: 'Give me one sentence about Agentuity.',
});
```

<Callout type="info" title="Service clients use AGENTUITY_SDK_KEY">
Service clients read `AGENTUITY_SDK_KEY` from the environment by default. `agentuity project create` writes it for registered projects, and `agentuity project import` can link an existing local app.
</Callout>

## 6. Deploy

```bash
agentuity deploy
```

or use the generated package script:

```bash
bun run deploy
```

During deploy, Agentuity detects the framework adapter and packages the app around the framework conventions you already use.

View deployments, logs, and project settings in the [Web App](https://app.agentuity.com).
