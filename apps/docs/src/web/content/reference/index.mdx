## When to Use What

| I want to... | Use |
|---|---|
| Write an agent handler (`ctx.*`) | [SDK Reference](/reference/sdk-reference) |
| Write an API route (`c.var.*`) | [SDK Reference](/reference/sdk-reference/router) |
| Access services from Next.js, Express, or scripts | [Standalone Packages](/reference/standalone-packages) |
| Call Agentuity services from any language via HTTP | [REST API Reference](/reference/api) |
| Create, deploy, or manage projects from the terminal | [CLI Reference](/reference/cli) |
