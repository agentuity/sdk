Use this reference when you need the API shape for v3 TypeScript packages. Most v3 apps use standalone clients in framework or server code. Hono apps can also use `@agentuity/hono` to receive service clients on `c.var`.

## Choose an SDK surface

| If your code is... | Start with | Use it for |
| --- | --- | --- |
| A framework route, server function, worker, or script | [Standalone Packages](/reference/standalone-packages) | Importing `KeyValueClient`, `QueueClient`, `SandboxClient`, and other service clients directly |
| A Hono app | [Frameworks](/frameworks) | Keeping framework routing while reading Agentuity clients from Hono context |
| Service-specific app logic | [Service Guides](/services) | Choosing KV, vector, queues, email, schedules, tasks, sandbox, auth, or Coder by job |
| Shared validation or structured model output | [Schema Validation](/reference/sdk-reference/schema) | Validating route inputs and function/tool inputs |
| Cross-language or non-TypeScript code | [REST API](/reference/api) | Calling Agentuity services over HTTP |
