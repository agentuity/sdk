## How to Read These

Use these pages when you know the app behavior you want but need the v3 shape. The examples use direct service clients first because they work in any server framework. Hono apps can also install `@agentuity/hono` and read the same clients from `c.var.*`.

Existing v2 runtime projects can keep using the supported v2 agent APIs. These v3 patterns use "agent" as an application design pattern, not as `createAgent()`.
