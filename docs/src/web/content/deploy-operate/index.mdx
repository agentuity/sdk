## Common Flow

```bash
agentuity project import
agentuity dev
agentuity build
agentuity deploy
```

Use [Local Development](/deploy-operate/local-development) when you want to run your framework server with Agentuity values injected. Use [Deploy Framework Apps](/deploy-operate/deploy-framework-apps) when the project is registered and the local build step succeeds.
