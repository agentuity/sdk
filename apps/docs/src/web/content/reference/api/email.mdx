Send and receive emails with managed addresses and webhook destinations.

<RegionPicker />

## Authentication

All requests require a Bearer token. Pass your SDK key in the `Authorization` header.

| Header | Value |
|--------|-------|
| `Authorization` | `Bearer YOUR_SDK_KEY` |

You can find your SDK key in the [Agentuity Console](https://app.agentuity.com) under your project settings.

## Address Management

### Create Address

Create a managed address at the `@agentuity.email` domain.

<ApiEndpoint method="POST" path="/email/addresses" />



#### Request Body

Address creation payload.

<ResponseFields fields={[
  {
    "name": "local_part",
    "type": "string",
    "description": "Local part before `@agentuity.email`",
    "required": true
  }
]} />

#### Response

Created `EmailAddress` object.

| Status | Description |
|--------|-------------|
| 200 | Address created |
| 401 | Unauthorized |

#### Example

<ApiExample method="POST" path="/email/addresses" body={{
  "local_part": "support"
}} />

## Sending Email

### Send Email

Send an email from an owned address. Delivery is asynchronous and total payload (including attachments) is capped at 25MB.

<ApiEndpoint method="POST" path="/email/outbound/send" />



#### Request Body

Outbound email payload.

<ResponseFields fields={[
  {
    "name": "from",
    "type": "string",
    "description": "The sender email address (must be owned by the organization)",
    "required": true
  },
  {
    "name": "to",
    "type": "string[]",
    "description": "The recipient email addresses",
    "required": true
  },
  {
    "name": "subject",
    "type": "string",
    "description": "The email subject",
    "required": true
  },
  {
    "name": "text",
    "type": "string",
    "description": "Plain text email body",
    "required": false
  },
  {
    "name": "html",
    "type": "string",
    "description": "HTML email body",
    "required": false
  },
  {
    "name": "attachments",
    "type": "object[]",
    "description": "File attachments",
    "required": false
  },
  {
    "name": "attachments[].filename",
    "type": "string",
    "description": "The filename for the attachment",
    "required": true
  },
  {
    "name": "attachments[].content",
    "type": "string",
    "description": "The base64-encoded content of the attachment",
    "required": true
  },
  {
    "name": "attachments[].contentType",
    "type": "string",
    "description": "The MIME content type of the attachment",
    "required": false
  },
  {
    "name": "headers",
    "type": "object",
    "description": "Custom email headers (e.g., In-Reply-To, References for threading)",
    "required": false
  }
]} />

#### Response

Created `EmailOutbound` object with initial `pending` status.

| Status | Description |
|--------|-------------|
| 200 | Outbound email accepted |
| 401 | Unauthorized |

#### Example

<ApiExample method="POST" path="/email/outbound/send" body={{
  "from": "support@agentuity.email",
  "to": [
    "user@example.com"
  ],
  "subject": "Welcome!",
  "text": "Thanks for joining Agentuity."
}} />
