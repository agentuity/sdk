## Common Flow

```bash
agentuity dev
agentuity project import
agentuity build
agentuity deploy
```

Use [Local Development](/deploy-operate/local-development) when you want to run your framework server with Agentuity values injected. Use [Deploy Framework Apps](/deploy-operate/deploy-framework-apps) when the app is ready to register, build, and upload.
