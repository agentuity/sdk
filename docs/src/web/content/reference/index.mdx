## When to Use What

| I want to... | Use |
|---|---|
| Install service clients in Node.js, Bun, scripts, workers, or server routes | [Standalone Packages](/reference/standalone-packages) |
| Inspect shared TypeScript helpers, schemas, workflow functions, or Coder APIs | [SDK Reference](/reference/sdk-reference) |
| Add Agentuity to Next.js, React Router, Hono, TanStack Start, or another framework app | [Framework Apps](/frameworks) |
| Run local dev, package, deploy, or manage projects from the terminal | [CLI Reference](/reference/cli) |
| Call Agentuity services from any language via HTTP | [REST API Reference](/reference/api) |
| Compare storage, messaging, observability, execution, and Coder services | [Service Guides](/services) |
