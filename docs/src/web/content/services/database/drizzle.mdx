Use `@agentuity/drizzle` when Bun app code needs Drizzle ORM queries against Agentuity-managed Postgres. The runtime client reads `DATABASE_URL` by default.

```bash
bun add @agentuity/drizzle@alpha drizzle-orm
```

```typescript
import { createPostgresDrizzle, eq } from '@agentuity/drizzle';
import * as schema from './schema';

const { db, close } = createPostgresDrizzle({ schema });

try {
  const activeUsers = await db
    .select()
    .from(schema.users)
    .where(eq(schema.users.active, true));

  const insertedUsers = await db
    .insert(schema.users)
    .values({ name: 'Alice', email: 'alice@example.com' })
    .returning();
} finally {
  await close();
}
```

## Define Your Schema

Use `@agentuity/drizzle/schema` in schema files. That entry point only re-exports Drizzle schema utilities, which keeps the schema import usable by `drizzle-kit`.

```typescript title="src/db/schema.ts"
import { boolean, pgTable, serial, text, timestamp } from '@agentuity/drizzle/schema';

export const users = pgTable('users', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  email: text('email').notNull().unique(),
  active: boolean('active').notNull().default(true),
  createdAt: timestamp('created_at').defaultNow(),
});
```

## Transactions

Use Drizzle's transaction API for atomic operations.

```typescript
import { eq, sql } from '@agentuity/drizzle';
import * as schema from './schema';

await db.transaction(async (tx) => {
  await tx
    .update(schema.accounts)
    .set({ balance: sql`balance - ${100}` })
    .where(eq(schema.accounts.name, 'Alice'));

  await tx
    .update(schema.accounts)
    .set({ balance: sql`balance + ${100}` })
    .where(eq(schema.accounts.name, 'Bob'));
});
```

## Configuration

The default driver is `pg`, backed by Agentuity's resilient `PostgresPool`. Set `driver: 'bun-sql'` only when you specifically need Bun SQL.

```typescript
import { createPostgresDrizzle } from '@agentuity/drizzle';
import * as schema from './schema';

const { db, client, close } = createPostgresDrizzle({
  schema,
  url: process.env.DATABASE_URL,
  logger: true,
  reconnect: { maxAttempts: 5 },
});
```

| Option | Default | Description |
|--------|---------|-------------|
| `schema` | none | Drizzle schema object |
| `url` | `DATABASE_URL` | PostgreSQL connection string |
| `connectionString` | `DATABASE_URL` | PostgreSQL connection string, kept for `pg`-style configuration |
| `connection` | none | Full `@agentuity/postgres` connection configuration |
| `driver` | `'pg'` | Database driver. Use `'bun-sql'` only when needed |
| `logger` | `false` | Enables Drizzle query logging or accepts a custom logger |
| `reconnect` | default pool config | Reconnection settings |
| `onConnect` | none | Callback after the initial connection is established |
| `onReconnected` | none | Callback when reconnection succeeds |

<Callout type="info" title="Runtime imports and schema imports are different">
Use `@agentuity/drizzle` from Bun app code that runs the database client. The runtime entry point currently imports Bun APIs even when `driver` is `'pg'`. Use `@agentuity/drizzle/schema` from schema files and migration tooling.
</Callout>

## Migrations

Use `drizzle-kit` to generate and apply migrations.

```bash
bun add -D drizzle-kit
```

```typescript title="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

const databaseUrl = process.env.DATABASE_URL;

if (!databaseUrl) {
  throw new Error('DATABASE_URL is required for Drizzle migrations');
}

export default defineConfig({
  schema: './src/db/schema.ts',
  out: './drizzle',
  dialect: 'postgresql',
  dbCredentials: {
    url: databaseUrl,
  },
});
```

```bash
bunx drizzle-kit generate
bunx drizzle-kit migrate
```

See the [Drizzle migrations documentation](https://orm.drizzle.team/docs/migrations) for migration modes and configuration options.

## Auth and User Tables

In v3 apps, keep authentication in your framework or identity provider, then use Drizzle for the user, account, or session tables your app owns.

```typescript
import { createPostgresDrizzle } from '@agentuity/drizzle';
import * as schema from './schema';

const { db, close } = createPostgresDrizzle({ schema });

try {
  await db.insert(schema.users).values({
    id: 'user_123',
    email: 'ada@example.com',
  });
} finally {
  await close();
}
```

See [Authentication](/services/authentication): choose between framework-owned sessions and Agentuity OIDC.
