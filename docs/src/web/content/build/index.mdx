## How to Use These

Use these pages when you know the behavior you want but need the v3 shape. The examples use direct service clients first because that path works across supported server frameworks and scripts. Hono apps can also install `@agentuity/hono` and read the same clients from `c.var.*`.

Legacy runtime apps can stay on the [v2 docs](https://v2.agentuity.dev). These pages use "agent" as an application design pattern, not as `createAgent()`.
